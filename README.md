# Plutocracy — Tradução PT-BR 🇧🇷

Tradução **não oficial**, feita por fãs, do jogo **Plutocracy** (Redwood) para o **português do Brasil**.

O jogo tem cerca de 8.300 textos, e todos foram traduzidos com contexto (não é tradução automática solta): menus, tutoriais, agentes, leis, eventos aleatórios, modo história, conquistas e a Plutocratopédia.

## Como instalar

1. Baixe este repositório: botão verde **Code → Download ZIP** (ou baixe o `.zip` na aba **Releases**).
2. Copie a pasta **`pt`** para dentro da pasta `translations` do jogo. O caminho padrão na Steam é:

   ```
   C:\Program Files (x86)\Steam\steamapps\common\Plutocracy\translations\
   ```

   Dica: na Steam, clique com o botão direito no jogo → **Gerenciar → Explorar arquivos locais**.

   No final, a estrutura deve ficar assim:

   ```
   Plutocracy\
   └── translations\
       ├── en\
       ├── es\
       ├── ...
       └── pt\        ← a pasta desta tradução
   ```

3. Abra o jogo e vá em **Opções → Selecionar idioma → Português (Brasil)**. Se o idioma não aparecer, reinicie o jogo.

## Observações

- Os carimbos em imagem ("Aprovado", "Falha" etc.) continuam em inglês, porque são figuras e não texto. Os outros idiomas do jogo também são assim.
- As datas usam o formato brasileiro (dd/mm/aaaa).
- Quando o jogo recebe atualizações com textos novos, eles podem aparecer em inglês até a tradução ser atualizada.

## Encontrou um erro?

Abra uma **Issue** com o texto errado (um print ajuda muito) ou mande um **Pull Request** com a correção. Os textos ficam nos arquivos `.xml` da pasta `pt`, no atributo `value="..."`.
